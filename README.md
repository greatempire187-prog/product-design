# Ugwoji Michael — Product Designer Portfolio

A static, frontend-only portfolio built with semantic HTML5, external CSS, and vanilla JavaScript. No build step, framework, backend, form service, or fabricated project evidence is included.

## Run locally

Open `index.html` in a browser, or serve the folder with any static HTTP server. For local development on Windows, VS Code's Live Server extension or another static server can serve the root. The portfolio uses client-side history routing and the development server should be configured with an SPA fallback to `index.html` for direct refreshes on nested paths.

## Deployment

The canonical URL and static hosting fallback are configured for the supplied GitHub Pages project URL. `404.html` forwards unknown GitHub Pages paths to the app, which restores the requested route. If deploying under a different base path or domain, update `base` in `script.js`, canonical/Open Graph URLs in `index.html`, `robots.txt`, and `sitemap.xml`.
